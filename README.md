# Fatih Mehmet Babacan

I build native, local-first macOS software with an emphasis on clear workflows, privacy, and dependable system behavior. My public projects are written in Swift and SwiftUI, support Apple Silicon and Intel Macs, and are developed in the open.

## Featured projects

### PortHarbor

A native macOS service radar that discovers local TCP listeners, connects them to processes and development projects, explains exposure and health, records a private 24-hour timeline, and provides a carefully validated Safe Stop workflow.

- Zero-configuration IPv4 and IPv6 discovery
- Process ancestry, project evidence, and protocol-aware health checks
- Developer ID signed and Apple-notarized releases
- Homebrew installation available through fmbabacan/tap

[Repository](https://github.com/fmbabacan/PortHarbor) · [Latest release](https://github.com/fmbabacan/PortHarbor/releases/latest) · [Documentation](https://github.com/fmbabacan/PortHarbor/tree/main/docs)

### FolioFold

A native macOS workspace for creating, editing, converting, organizing, signing, and exporting PDF and Folio documents. Document operations run locally without uploading files to a service.

- Native Swift and SwiftUI interface
- Local-first document workflows
- Apple Silicon and Intel support
- Apache-2.0 licensed

[Repository](https://github.com/fmbabacan/FolioFold) · [Issues](https://github.com/fmbabacan/FolioFold/issues) · [Contributing](https://github.com/fmbabacan/FolioFold/blob/main/CONTRIBUTING.md)
