## Featured project

### [FolioFold](https://github.com/fmbabacan/FolioFold)

A native macOS workspace for creating, editing, converting, organizing, signing, and exporting PDF and Folio documents. Document operations run locally, without uploading files to a service.

- Built with Swift and SwiftUI
- Supports Apple Silicon and Intel Macs
- Apache-2.0 licensed
- Contributions, bug reports, and focused feature proposals are welcome
